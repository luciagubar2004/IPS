# Indoor Positioning System (IPS) based on RSSI

This project implements a prototype for indoor localization using WiFi signal strength (RSSI). It is designed to address the challenges of positioning in environments where GPS signals are unreliable or unavailable.

## 🚀 Overview
The system captures and processes signal data from multiple access points to estimate the relative position of a device. This project highlights the application of digital signal processing and logic to real-world telecommunication challenges.

## 🛠️ Tech Stack
- **Language:** Python
- **Core Concepts:** Signal Propagation, RSSI Analysis, Data Filtering.

## 📈 Key Features
- Real-time data parsing from WiFi networks.
- Basic signal filtering to mitigate environmental noise and fluctuations.
- Lightweight implementation suitable for edge-like constraints.

## 💡 Why this project?
As a Telecommunication Engineering student, I am fascinated by how we can use existing infrastructure (like WiFi) to solve complex spatial problems. This project served as a starting point for my current interest in **Edge AI** and privacy-focused local processing.
